## ✨ Features
- Animated particle canvas background (data analyst aesthetic)

- Active nav highlight as you scroll

- Contact form with mailto fallback (no backend needed)
- Floating tech-pill cards in hero

## 🚀 How to Use

### Open Locally
Just double-click `index.html` or open it in any browser. No build step needed.

### Customize
1. **Your Info**: Edit `index.html` — update name, links, project details, etc.
2. **Colors**: Edit `css/style.css` — change CSS variables in `:root { }` at the top
3. **Download CV**: Place your resume PDF as `resume.pdf` in the root folder — the "Download CV" button will work automatically
4. **Add Projects**: Copy a `.project-card` block in the Projects section of `index.html`

### Deploy (Free)
- **GitHub Pages**: Push to a repo → Settings → Pages → Deploy from main branch
- **Netlify**: Drag & drop the portfolio folder at netlify.com/drop
- **Vercel**: `vercel deploy` in the folder
